# oneless: Audio Visualizer

🌐 **[Открыть сайт проекта](https://sa1dsa1dsa1dsa1d.github.io/oneless-team/)**

Проект команды **oneless**. Основная разработка — утилита **Visualizer** для визуализации системного звука в реальном времени.

## О проекте

Аудиовизуализатор, написанный на Python. Программа захватывает звук, который воспроизводится на компьютере (через WASAPI Loopback на Windows), и отображает его в виде различных графиков и индикаторов.

### Возможности
- Захват системного аудио без виртуальных кабелей (на Windows).
- Спектральный анализ (FFT) с логарифмической шкалой частот.
- Осциллограф с триггером для стабильной картинки.
- Стереометр (вектороскоп) для оценки стереопанорамы.
- Индикаторы уровня (LUFS) с пиковыми значениями.
- Водопад (спектрограмма) с режимами прокрутки и слоев.
- 3D-куб, вращающийся в такт музыке.
- Поддержка светлой и темной тем оформления.
- Сборка в независимый `.exe` файл.

## Стек технологий
- **Python 3.x**
- **Pygame** (отрисовка интерфейса)
- **PyAudioWPatch** (захват звука, только Windows)
- **NumPy** (математика и FFT)
- **PyInstaller / py2app** (сборка в исполняемые файлы)

## Установка и запуск

Для запуска из исходного кода потребуется установленный Python (версия 3.8 или выше).

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/sa1dsa1dsa1dsa1d/oneless-team.git
   cd oneless-team
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите скрипт:
   ```bash
   python blackbone.py
   ```

## Сборка (Компиляция)

Проект можно скомпилировать в независимый исполняемый файл, чтобы запускать его без установленного Python. 

### Windows (Сборка в EXE)
Сборка производится с помощью **PyInstaller**.
1. Установите PyInstaller:
   ```bash
   pip install pyinstaller
   ```
2. Выполните сборку из корня проекта:
   ```bash
   pyinstaller --noconsole --onefile --name "Visualizer" blackbone.py
   ```
3. Готовый файл `Visualizer.exe` появится в папке `dist/`.

> **Важно:** PyInstaller не является кросс-компилятором. Сборку для Windows нужно запускать только на Windows.

### Linux (Сборка бинарника)
1. Установите системные зависимости (пример для Debian/Ubuntu):
   ```bash
   sudo apt install python3-dev python3-pip libportaudio2
   ```
2. Установите PyInstaller:
   ```bash
   pip install pyinstaller
   ```
3. Соберите бинарник:
   ```bash
   pyinstaller --onefile --name "Visualizer" blackbone.py
   ```
4. Запустите `./dist/Visualizer`.

### macOS (Сборка .app)
Для macOS стандартный PyInstaller работает, но для создания полноценного `.app` бандла лучше использовать **py2app**.
1. Установите зависимости:
   ```bash
   pip install py2app
   ```
2. Создайте минимальный `setup.py` в папке проекта:
   ```python
   from setuptools import setup
   APP = ['blackbone.py']
   OPTIONS = {'argv_emulation': False, 'packages': ['pygame', 'numpy', 'pyaudiowpatch']}
   setup(app=APP, options={'py2app': OPTIONS}, setup_requires=['py2app'])
   ```
3. Запустите сборку:
   ```bash
   python setup.py py2app
   ```
4. Готовое приложение `Visualizer.app` появится в папке `dist/`.

## Подводные камни захвата звука

Визуализатор использует `PyAudioWPatch` (обертка над WASAPI) для захвата системного аудио (Loopback). Это работает «из коробки» только на Windows. На других платформах есть ограничения, связанные с политиками безопасности ОС.

### Windows
- **Статус:** Работает нативно.
- **Нюанс:** Захват идет через WASAPI Loopback. Если у пользователя несколько аудиоустройств, скрипт пытается найти устройство по умолчанию. Если звук не визуализируется, возможно, звук воспроизводится через эксклюзивный режим (ASIO) или устройство не поддерживает Loopback на аппаратном уровне.

### macOS
- **Статус:** Требует установки виртуального аудиодрайвера.
- **Проблема:** macOS (начиная с 10.15 Catalina) не позволяет приложениям напрямую захватывать системный звук из соображений безопасности. Встроенного Loopback, как в Windows, здесь нет.
- **Решение:** Пользователь обязан установить виртуальное аудиоустройство, например **BlackHole** (или Soundflower).
- **Инструкция для пользователя:**
  1. Установить BlackHole (через Homebrew: `brew install blackhole-2ch`).
  2. Открыть «Аудио MIDI Setup» (Audio MIDI Setup).
  3. Создать **Multi-Output Device** (Многовыходное устройство), включив в него основные динамики и BlackHole.
  4. Выбрать это Multi-Output Device как устройство вывода звука в системе.
  5. В скрипте визуализатора выбрать входное устройство `BlackHole 2ch` (либо скрипт должен уметь автоматически находить его по имени).
- **Разрешения:** При первом запуске macOS запросит разрешение на «Запись экрана» или доступ к микрофону.

### Linux
- **Статус:** Зависит от звукового сервера.
- **Проблема:** Прямого доступа к системному микшеру через PyAudio нет. `pyaudiowpatch` не работает на Linux.
- **Решение:** Необходимо использовать PulseAudio или PipeWire.
  - Если используется PulseAudio, захват обычно идет через `Monitor of <Device>` (Монитор устройства вывода). В списке устройств нужно выбирать именно «Monitor»-источник, а не физический микрофон.
  - На PipeWire аналогично нужно выбрать источник мониторинга.
  - В некоторых случаях требуется установка пакета `pulseaudio-utils`.

## Известные ограничения

1. **Кроссплатформенность кода:** 
   Текущий код использует Windows-специфичные вызовы:
   ```python
   import pyaudiowpatch as pyaudio
   ...
   def start_drag_window():
       hwnd = pygame.display.get_wm_info()["window"]
       ctypes.windll.user32.ReleaseCapture()
       ctypes.windll.user32.SendMessageW(hwnd, 0xA1, 0x2, 0)
   ```
   На Linux и macOS этот код вызовет `ModuleNotFoundError` и `AttributeError`. Для работы на этих ОС необходимо заменить аудио-бэкенд (например, на `sounddevice`) и обернуть вызовы `ctypes.windll` в проверку платформы:
   ```python
   import sys
   if sys.platform == "win32":
       # Использовать pyaudiowpatch и ctypes.windll
   else:
       # Использовать sounddevice и альтернативный метод перетаскивания
   ```

2. **Разрешения:** 
   На macOS и Linux антивирусы и системы безопасности могут блокировать доступ к аудиоустройствам для неподписанных бинарников.
